# 舞会助手第一版

用户已同意的范围：只处理当前人物，补满三颗当局爱心，完成可用情报及好感度问答，然后停止；不自动找人、闲逛、跳舞、比美、购物、换装或进入下一场。

运行时不调用 GPT 或任何网络 API。使用 macOS 14+ 原生 SwiftUI、ScreenCaptureKit、Vision OCR 和 CoreGraphics 鼠标事件。仅捕获 iPhone 镜像窗口。程序自行获取屏幕录制和辅助功能权限；权限由用户在系统设置中授予。

用户校准游戏矩形；坐标保存在游戏区域内，相对坐标适应窗口缩放，点击前复核窗口及人物。开启时锁定当前人物。三颗爱心在角色铭牌上方固定区域以红色覆盖率识别；识别不确定时暂停。OCR 识别菜单、话题、题目与答案，数据直接从用户本地攻略器导出并保留来源。

聊天选偏好话题，然后固定位置跳过；打听情报后同样跳过。跳过键位于底部控制条最左侧，不使用右下角箭头。出现结算提示时点屏幕中央。问答不可跳过，依据已有题目/答案映射判断，未知题目暂停。识别逻辑与点击驱动分离，离线图片和录屏可以验证识别、模拟动作而不接触游戏。

界面包含识别预览、矩形校准、权限状态、开始/暂停/停止、仅观察模式和本地操作记录。全局 Control+Option+S 停止，鼠标移至主屏左上角停止，单次最多 80 次动作/8 分钟，异常停机不继续点击。启动默认仅观察，用户明确关闭后才允许实际操作。

验收：核心状态机和答案映射测试通过；真实录屏样本识别验证；编译生成可双击的 .app 与包含源码的 zip；权限若尚未授予明确告知现场验证边界。
