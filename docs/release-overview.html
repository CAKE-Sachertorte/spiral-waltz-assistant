舞会助手 Waltz Assistant

完全本地运行的 macOS 舞会游戏自动化助手——不需要 API Key，不上传截图，开箱即用。

核心特性

  • 本地运行
    全程离线，不联网、不上传任何截图
  • 无需 API Key
    开箱即用，不用注册任何服务
  • Vision 识别
    原生识别游戏画面与铭牌
  • 自动通关
    满心、情报收集、问答一站完成
  • 安全可控
    演练模式先观察再执行
  • 随时停止
    快捷键 / 鼠标移角即停

系统要求

芯片　Apple Silicon (M1/M2/M3…)
系统　macOS 14 及以上
依赖　已连接的 iPhone 镜像竖屏窗口
权限　屏幕录制 + 辅助功能

快速上手

  1. 解压安装包，双击 舞会助手.app 打开；把游戏停在当前人物的互动菜单（能看到铭牌、三颗爱心和「和他/她聊聊」按钮）。
  2. 在程序里点「屏幕录制」和「辅助功能」，到系统设置里为舞会助手本身授权，授权后重开程序。
  3. 点「识别窗口」→「拖框校准」，圈出完整手机游戏画面（排除镜像顶部工具栏和灰色边框），再点「识别窗口」核对人物与爱心。
  4. 保持「仅观察，不点击游戏」开启，点「演练当前人物」核对要执行的第一步。
  5. 确认无误后关闭「仅观察」，点「运行当前人物」——程序自动完成满心、情报和问答后停止。
运行期间不要操作手机、切换人物或遮挡镜像窗口。随时可用 Control+Option+S 停止，或把鼠标移到主屏幕左上角停止。

技术信息

  • 语言 / 框架：Swift · SwiftPM 原生包
  • 识别引擎：Apple Vision 框架（OCR + 图像匹配）
  • 包含组件：WaltzCore（核心库）、WaltzAssistant（主程序）、WaltzInspect（调试工具）
