舞会助手 Waltz Assistant

为《螺旋圆舞曲》舞会流程准备的 macOS 小助手。自动处理聊天、情报与好感问答，让重复操作轻松一点。画面识别与决策均在本机完成，无需 API Key，不上传截图。

核心特性

  • 本地识别
    使用 Apple Vision 读取画面，截图不上传云端
  • 两种画面来源
    支持 iPhone 镜像与 Mac 游戏客户端
  • 处理日常互动
    补满爱心、收集情报，按内置攻略回答问题
  • 可选自动切人
    支持跳舞、比美；完成后可闲逛寻找下一位
  • 先观察，再执行
    默认仅观察，可先核对识别结果与下一步操作
  • 随时暂停或停止
    支持按钮、快捷键与鼠标移至左上角停止

系统要求

芯片　Apple Silicon（M 系列）
系统　macOS 14 或更高版本
画面　Mac 游戏客户端 / iPhone 镜像
权限　屏幕录制与辅助功能

快速上手

  1. 解压应用包，打开 舞会助手.app。启动游戏客户端或连接 iPhone 镜像，把游戏停在当前人物的互动菜单，确保铭牌、爱心与操作按钮清晰可见。
  2. 在助手中点击「屏幕录制」和「辅助功能」，按提示到系统设置为舞会助手授权，再退出并重新打开助手。
  3. 选择对应的「画面来源」，点击「识别窗口」，需要时用「拖框校准」圈出完整游戏内容，排除标题栏及两侧边框。再次识别，核对人物与爱心。
  4. 保持「仅观察，不点击游戏」开启，点击「演练当前人物」，核对准备执行的第一步；此时不会点击游戏。
  5. 确认无误后关闭「仅观察」，点击「运行当前人物」。不开启「自动切人」时，当前人物流程完成后停止；开启后会通过闲逛寻找下一位，直到识别到没有新人物的提示或遇到需要处理的情况。
运行时请让游戏窗口保持前台，避免同时手动操作或移动、缩放窗口。可随时按 Control+Option+S，或将鼠标移到主屏幕左上角停止。遇到无法可靠识别的画面或答案时，助手会等待或停止，请查看操作记录。

使用说明

  • 内置 53 位角色、22 类题目的攻略数据；实际操作以当前画面识别和攻略匹配结果为准。
  • 不自动购买、换装或充值。助手本身无需连接 AI 服务，游戏仍需正常联网。
  • 本项目是独立开源工具，与游戏官方无关联。

技术信息

  • 开发语言与构建：Swift · Swift Package Manager
  • 画面识别：Apple Vision 文字识别，结合本地图像特征判断
  • 包含组件：WaltzCore（核心库）、WaltzAssistant（主程序）、WaltzInspect（调试工具）
