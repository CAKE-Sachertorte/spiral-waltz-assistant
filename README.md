# 舞会助手 v1.3.6

运行时完全本地，不调用 GPT，不需要 API Key，不上传截图。适用于 Apple Silicon Mac、macOS 14 及以上、Mac 游戏客户端或已连接的 iPhone 镜像窗口。

## 使用

1. 解压 `dist/舞会助手-v1.3.6-mac-arm64.zip`，打开其中的 `舞会助手.app`。把游戏停在**当前人物的互动菜单**，能看到角色铭牌、三颗爱心以及“和他/她聊聊”等按钮。也可以从已识别的结算或普通对话页启动。若上次已停在问答页，铭牌可识别且已满心，也可以直接重新运行以继续答题。
2. 点击程序里的“屏幕录制”和“辅助功能”，在系统设置中**为舞会助手本身**授权。Codex 的权限不会自动转给这个独立程序。授权后若状态未生效，退出并重开。开发版更新后若开关已开但程序仍提示无权限，在对应列表移除旧“舞会助手”，再通过“+”添加当前应用并重开。
3. 点击“识别窗口”。点击“拖框校准”，在右侧预览上圈出完整手机游戏画面，排除镜像顶部工具栏和灰色边框；常规 iPhone 镜像也可以先试“常用窗口布局”。再点“识别窗口”，核对人物和爱心与实际一致。
4. 保持“仅观察，不点击游戏”开启，点“演练当前人物”，核对准备执行的第一步。演练只观察和记录，不会自动改变游戏。
5. 确认正确后关闭“仅观察”，点击“运行当前人物”。程序把镜像切到前台；运行期间不要操作手机、切换人物或遮挡镜像窗口。
6. 完成当前人物的满心、可用情报和问答后自动停止。可以用暂停/停止按钮，或 **Control+Option+S** 随时停止；把鼠标移到主屏幕左上角也会停止。

## 执行规则

- 爱心未满：打开聊天，只选攻略库中的偏好话题；选完直接点击底部控制条最左侧跳过键。没有偏好话题则返回刷新，连续多次没有则停止。
- 爱心已满：完成仍可用的“打听情报”，同样直接跳过；情报可能不止一条。
- 若出现“好感度问答”：识别题目与可见选项，对照本地攻略数据选择。优先按当前人物的正确答案文本集合，匹配可见选项中的唯一答案，不依赖题干或原选项顺序。“结构问题／体制问题”等已核实表述按别名匹配；多个命中或没有命中时，再结合完整题目和选项判断，仍不确定则停止。问答阶段优先局部 OCR 选项与人物铭牌，不能可靠匹配时读取完整画面。
- 结算提示及普通不可跳过对白点击**屏幕中央**。不点击右下角箭头。
- 保留用户新增的跳舞／比美流程及“自动切人”开关。开启自动切人后，通过闲逛检索下一人物；不开启时处理完当前人物停止。不自动购买、换装、充值或进入下一场。
- 单次最多 80 次鼠标点击或 8 分钟；聊天最多 25 次；界面长期不变、未知画面、镜像断开、失去焦点、窗口遮挡/切换均停止。

## 校准与识别限制

第一版按这次录屏中的竖屏布局识别：游戏画面宽高比约 0.46，角色铭牌和爱心位于固定区域。窗口等比例缩放可适配；更换设备比例、游戏布局、字体或镜像显示方式后需要重新校准。爱心粒子动画、画面切换或文字尚未显示完全时会等待稳定画面。

真实录屏和现场妮柯斯页面已用于验证菜单、人物铭牌、满心与 2/3 心、对白跳过键和结算场景。v1.0.1 增加菜单局部 OCR，修复暗色“和她聊聊”按钮被整屏 OCR 漏掉的问题。v1.0.2 增加亮心的红色通道亮度要求，修复安德烈半透明未点亮爱心透出服装颜色时被判为“不确定”的问题。识别结果不确定时程序停止。妮柯斯已完成一次现场完整流程：2/3 心 → 3/3 心 → 两条情报 → 颜色问答 → 自动停止。v1.0.2 也已现场完成安德烈的 2/3 心 → 满心 → 两条情报 → 自动停止。其他人物第一次运行请留在屏幕前观察。

## 数据与文件

- 攻略：`Sources/WaltzCore/Resources/guide.json`，从原有 `螺旋圆舞曲攻略器.html` 导出，包含 53 位角色和 22 类问答。文件包含原始数据 SHA-256。
- 更新攻略：在项目目录运行 `node tools/export-guide.mjs /完整路径/螺旋圆舞曲攻略器.html`，再重新打包。
- 设置：系统 UserDefaults 中的 `com.th.waltzassistant`，只保存校准区域。
- 运行记录：`~/Library/Application Support/WaltzAssistant/operations.log`。不自动保存游戏截图。

## 从源码运行 / 验证

需要 Apple Command Line Tools（本次环境已有），无需下载依赖。

```sh
swift run --build-system native WaltzTests
swift run --build-system native WaltzAssistant
bash tools/package.sh
```

测试以独立可执行文件运行，避免仅安装 Command Line Tools 时缺少 XCTest 的问题。

打包脚本在系统临时目录完成签名并输出 zip，避免桌面同步服务给 `.app` 添加 Finder 元数据而影响签名。请在“下载”目录解压使用；不要把应用放进本项目的同步桌面目录。源码和 zip 可以正常存放在项目目录。

离线检查图片，不发送点击：

```sh
swift run --build-system native WaltzInspect /完整路径/截图.png 0.122,0.075,0.757,0.846
```

最后四个数字是截图中的游戏区域 `x,y,宽,高`（0–1）；示例值只适用于这次录屏的黑边布局。输出包含 OCR 文本、位置、爱心覆盖率与场景。

提取录屏帧用于离线检查：

```sh
swift run --build-system native WaltzInspect --video /完整路径/录屏.mov /输出目录 30 20 14
```

技术接口参考：[Apple Vision](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)、[ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager)。

基于用户自行增加跳舞、比美及自动切人的当前源码继续修改。启动时已在结算页也会点击中央；已识别的普通对话会自动推进，无需先从 NPC 菜单发起任务。偷听事件只选择明确识别出的“不偷听”选项。识别到“基本上都和大家见过了……”或“如果想要和人聊天……直接找他们比较快”任一句明确结束提示即停止，不再继续闲逛。未知画面、未知答案仍等待或停止。仅离线检查，由用户现场测试。

## v1.2.1 流程容错与闲逛响应

比美／跳舞后其他 NPC 插话或好感度结算继续点中央，普通对话不覆盖已锁定的答题人物；明确的新人物菜单仍按自动切人阶段确认。启动在玛格达待机菜单时直接闲逛。告别后优先局部识别右侧菜单，确认闲逛及另一导航按钮后立即点击，不再等待整屏 OCR 逐字一致；不盲点固定坐标。话题页在返回按钮漏识别时，可由至少两个已知话题确认，避免雷斯林的话题被误当作问答。包含之前修复，仅离线检查，由用户现场测试。

## v1.2.2 右侧问答选项局部识别

问答局部 OCR 同时支持左右两侧选项及两侧人物铭牌。玛格达发言时，仅在完整读出已收录选项组后采用局部结果，答题对象仍由当前运行中记住的 NPC 决定；选项不完整则继续全屏识别。匹配失败的提示显示实际读到的选项。黛咪通婚截图离线验证为第 3 项“错在阶级”；未现场验证，由用户测试。

## v1.2.3 比美跳过与闲逛结束提示

比美／跳舞跳过只点击 OCR 识别出的白字“跳过”位置，不再回退到固定坐标；全屏漏读时补充右下按钮区域局部 OCR。按钮仍在就按实际位置重试，未识别按钮或结算时等待，不提前点结算中央。识别到“如果想要和人聊天……似乎还是直接找”这一明确结束前半句也停止，不必等后续文字完整出现；结束提示不再等待两帧整屏文字稳定。仅离线验证，由用户现场测试。

## v1.3.0 原生 Mac 客户端与菜单跳过修复

## v1.3.6 更新与纠错（2026-11-27）
